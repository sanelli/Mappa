# 📦 Mappa NuGet packages
- [Mappa](https://www.nuget.org/packages/Mappa/): attributes and `MappaContext` used to drive the source generator;
- [Mappa source generator](https://www.nuget.org/packages/Mappa.Generator/): source generator that automatically generates mappings between classes and value types.

For MongoDB Bson and Google Protobuf well-known types, reference [MongoDB.Bson](https://www.nuget.org/packages/MongoDB.Bson/) or [Google.Protobuf](https://www.nuget.org/packages/Google.Protobuf/) in your project and enable `BsonWellKnownTypes` / `ProtobufWellKnownTypes` on `[MappaSettings]` (see [tutorial](./tutorial.md#bson-and-protobuf-well-known-types)). The former `Mappa.Dependency.Bson` / `Mappa.Dependency.Protobuf` packages (and their DependencyInjection companions) have been removed.
