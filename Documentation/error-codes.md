# Errors and warnings
The following table describes the errors and warnings that can be produced by the Mappa source generator:

| Code    | Type | Description                                                                                                                                                  | How to solve it                                                                                                                                                                                                       |
|---------|------|--------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MP00000 | ℹ️   | Mappa debug diagnostic, used to display debug and information messages when `mappa.debug` is set to `true` in the `.editorconfig`.                            |                                                                                                                                                                                                                         |
| MP00001 | ⛔️   | The partial method has an invalid number of parameters, therefore it cannot be generated.                                                                    | Implement the method yourself, apply the `[MappaIgnore]` attribute, or fix the number of parameters to be 1 or 2 (the second must be of type `MappaContext`).                                                         |
| MP00002 | ⛔️   | The second parameter of the method is not of type `MappaContext`.                                                                                            | Implement the method yourself, apply the `[MappaIgnore]` attribute, or change the type of the second parameter to `MappaContext`.                                                                                     |
| MP00003 | ⛔    | The method returns `void`.                                                                                                                                   | Implement the method yourself, apply the `[MappaIgnore]` attribute, or change the return type.                                                                                                                        |
| MP00004 | ⛔    | The method returns a `Task` type.                                                                                                                            | Implement the method yourself, apply the `[MappaIgnore]` attribute, or change the return type.                                                                                                                        |
| MP00005 | ⛔    | A mapping for the same type already exists in the mapper.                                                                                                    | Remove one of the methods, change their return type or the type of their first parameter, or apply the `[MappaIgnore]` attribute.                                                                                       |
| MP00006 | ⛔    | A strategy cannot be identified.                                                                                                                             | Change the source type or the target type, implement the mapping yourself, or apply the `[MappaIgnore]` attribute.                                                                                                    |
| MP00007 | ⛔    | Multiple attributes target the same parameter or property (including `[MappaIgnoreTargetProperty]` combined with another target-name attribute).              | Remove one or more of the attributes targeting the same property or constructor parameter.                                                                                                                              |
| MP00008 | ⛔    | Cannot detect a suitable method to invoke when using the `[MappaInvokeMethod]` attribute.                                                                    | Remove the `[MappaInvokeMethod]` attribute or make sure the desired method exists.                                                                                                                                      |
| MP00009 | ⛔    | The type cannot be correctly identified when using the `[MappaInvokeMethod]` attribute.                                                                      | Remove the `[MappaInvokeMethod]` attribute or make sure the desired type exists.                                                                                                                                        |
| MP00010 | ⛔    | The field or property cannot be identified when using the `[MappaInvokeMethod]` attribute.                                                                   | Remove the `[MappaInvokeMethod]` attribute or make sure the desired field or property exists on the mapper class or an accessible base class.                                                                           |
| MP00011 | ⛔    | The `[MappaAssignFromContext]` attribute cannot be used when the method does not have a `MappaContext` as second parameter.                                  | Remove the `[MappaAssignFromContext]` attribute or add a `MappaContext` parameter as the second parameter.                                                                                                              |
| MP00012 | ⚠️   | The user has defined `UserDefined` for `CultureInfoSetting` but `CultureName` has not been defined.                                                          | Remove the usage of `UserDefined` culture settings, replace the culture setting with invariant or current culture, or define a culture name.                                                                           |
| MP00013 | ⚠️   | The settings define a format but not a culture, therefore the `ParseExact` method cannot be used.                                                             | Remove the format or define a culture in the settings.                                                                                                                                                                  |
| MP00014 | ⚠️   | The property setter is not accessible and therefore the property cannot be mapped.                                                                           |                                                                                                                                                                                                                         |
| MP00015 | ⛔    | The method has too many `[MappaUseProperty]` attributes targeting the same property.                                                                         | Remove the `[MappaUseProperty]` in excess.                                                                                                                                                                              |
| MP00016 | ⚠️   | A dependency introduced via `[MappaDependency]` attribute or `[MappaStaticDependency]` attribute does not provide any method that could be used for mapping. | Remove the dependency.                                                                                                                                                                                                  |
| MP00017 | ⚠️   | A non required property cannot be mapped and therefore will be ignored.                                                                                      | The warning can be ignored if this is expected, apply `[MappaIgnoreTargetProperty]` to exclude the property from empty-constructor mapping, or apply any of the mapping attributes to that property (`[MappaAssignFromConstant]`, `[MappaAssignFromContext]`, `[MappaInvokeMethod]`, `[MappaUseProperty]`). |
| MP00018 | ⛔    | The target type on the attribute `[MappaTypeMappingDefault]` is not a subtype of the type returned by the method being mapped                                | Remove or update the attribute so that the target type is a subtype of the type returned by the method the attribute is applied to.                                                                                     |
| MP00019 | ⛔    | Attribute `[MappaTypeMappingDefault]` require the name of a method but no method name is specified.                                                          | Add the method name or change the `[MappaTypeMappingDefault]` default behavior.                                                                                                                                         |
| MP00020 | ⛔    | Attribute `[MappaTypeMappingDefault]` specify a method that cannot be found or is not suitable for mapping                                                   | Update the method used or change the default behavior for the Attribute `[MappaTypeMappingDefault]` attribute.                                                                                                          |
| MP00021 | ⛔    | The type provided to the `[MappaTypeMappingDefault]` attribute must be an exception                                                                          | Update the type used or change the default behavior for the Attribute `[MappaTypeMappingDefault]` attribute                                                                                                             |
| MP00022 | ⛔    | The type provided must be concrete (i.e. not abstract or an interface).                                                                                      | Provide a concrete type.                                                                                                                                                                                                |
| MP00023 | ⛔    | The type provided must have a constructor with no parameters or a constructor with a single string parameter.                                                | Provide a type that satisfy the requirements.                                                                                                                                                                           |
| MP00024 | ⛔    | Attribute `[MappaTypeMappingDefault]` does not specify a valid behavior.                                                                                     | Update the attribute to specify a valid behavior.                                                                                                                                                                       |
| MP00025 | ⚠️   | Attribute `[MappaTypeMappingDefault]` specify a type, but that type will not be used.                                                                        | Remove the type or update the behavior.                                                                                                                                                                                 |
| MP00026 | ⛔    | Two or more `[MappaTypeMapping]` attributes have the same source type.                                                                                       | Remove the extra attributes from the method.                                                                                                                                                                            |
| MP00027 | ⛔    | Attribute `[MappaTypeMapping]` has the same source type of the type being mapped.                                                                            | Remove the attribute and rely on the `[MappaTypeMappingDefault]` attribute to specify the mapping for the default behavior.                                                                                             |
| MP00028 | ⛔    | Attribute `[MappaTypeMappingDefault]` source type is not derived from the source type of the method being mapped.                                            | Remove or update the attribute.                                                                                                                                                                                         |
| MP00029 | ⛔    | Attribute `[MappaTypeMappingDefault]` target type is not derived from the return type of the method being mapped.                                            | Remove or update the attribute.                                                                                                                                                                                         |
| MP00030 | ⛔    | A field or a property cannot be used because it is not `static`.                                                                                             | Add the `static` attribute to the field or property if possible, or replace the usage of the field with a different one.                                                                                                |
| MP00031 | ⚠️   | A `[MappaUseProperty]` source property will not be used because another mapping attribute (`[MappaAssignFromContext]` or `[MappaAssignFromConstant]`) targets the same property or constructor parameter. | Remove the `[MappaUseProperty]` attribute or remove the conflicting attribute.                                                                                                                                          |
| MP00032 | ⚠️   | A `[MappaUseProperty]` source property will not be used because the method invoked via `[MappaInvokeMethod]` does not require the source property.           | Remove the `[MappaUseProperty]` attribute, change the invoked method to accept the source property, or remove `[MappaInvokeMethod]` if the source property mapping is intended.                                          |
| MP00033 | ⚠️   | A mapping attribute targets a property or constructor parameter that does not exist on the target type.                                                      | Fix the target name in the attribute so that it matches an existing property or constructor parameter on the target type, or remove the attribute.                                                                        |
| MP00034 | ⛔    | The method has too many `[MappaIgnoreTargetProperty]` attributes targeting the same property.                                                                | Remove the extra `[MappaIgnoreTargetProperty]` attributes targeting the same property.                                                                                                                                  |
| MP00035 | ⛔    | The target property or field for `[MappaAssignToContext]` does not exist or is not accessible.                                                               | Fix the target member name in the attribute, make the member accessible, or remove the attribute.                                                                                                                        |
| MP00036 | ⚠️   | `[MappaAssignToContext]` is ignored because the map method does not have a `MappaContext` parameter.                                                       | Add a `MappaContext` parameter to the map method or remove the attribute.                                                                                                                                               |
| MP00037 | ⛔    | Multiple `[MappaAssignToContext]` attributes on the same method use the same context key.                                                                  | Use distinct context keys or remove the duplicate attributes.                                                                                                                                                           |
| MP00038 | ⚠️   | A `MappaSettings` `DateTimeStyles` or `NumberStyles` property has an integer value that is not a valid enum combination.                                     | Use defined enum members or valid flag combinations in `[MappaSettings]`; unrecognized bits are ignored in generated parse code.                                                                                        |
| MP00039 | ⚠️   | Not all source enum members can be mapped to the target enum.                                                                                                | Add matching members to the target enum (by name, numeric value, or Description depending on `EnumToEnumMapSetting`), remove or rename unmapped source members, or ignore the warning if unmapped values are not expected at runtime; unmapped source values throw `ArgumentOutOfRangeException`. |
| MP00040 | ⛔    | An enum member is missing a non-empty `[Description]` attribute required for Description mapping.                                                            | Add a non-empty `[Description]` to every enum member used in the mapping, or change `EnumStringMapSetting` / `EnumToEnumMapSetting` to match by member name or numeric value instead.                                                                                                         |
| MP00041 | ⛔    | Enum mapping is ambiguous because multiple members map to the same target.                                                                                   | Ensure each source member maps to a unique target member; resolve duplicate Description values or case-insensitive name collisions on the involved enums.                                                                                                                                       |
| MP00042 | ⛔    | Invoke method resolution is ambiguous because multiple methods match.                                                                                        | Disambiguate the candidate methods (e.g. remove duplicate static/instance overloads, or resolve conflicting parameter counts for polymorphism default invoke-method lookup); only one method may match at the same selection tier after hierarchy tie-breaking.                                  |
