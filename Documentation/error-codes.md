# Errors and warnings
The follow table describe the list of errors and warnings that can be produced by the Mappa source generator:

| Code    | Type | Description                                                                                                                                                  | How to solve it ?                                                                                                                                                                                                       |
|---------|------|--------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MP00000 | ℹ️   | Mappa debug, used to display debug and information information when `mappa.debug` is set to `true` in the `.editorconfig`                                    |                                                                                                                                                                                                                         |
| MP00001 | ⛔️   | The partial method has an invalid number of parameters, therefore is cannot be generated.                                                                    | Implement the methods yourself, or apply the `[MappaIgnore]` attribute or fix the number of parameters to be 1 or 2 (the second must be of type `MappaContext`.                                                         |
| MP00002 | ⛔️   | The second parameter of the method is not of type `MappaContext`.                                                                                            | Implement the methods yourself, or apply the `[MappaIgnore]` attribute or change the type of the second parameter to be `MappaContext`.                                                                                 |
| MP00003 | ⛔    | The method returns `void`.                                                                                                                                   | Implement the methods yourself, or apply the `[MappaIgnore]` attribute or change the return type.                                                                                                                       |
| MP00004 | ⛔    | The method returns a `Task` type.                                                                                                                            | Implement the methods yourself, or apply the `[MappaIgnore]` attribute or change the return type.                                                                                                                       |
| MP00005 | ⛔    | A mapping for the same type already exists in the mapper.                                                                                                    | Remove one of the methods or change their return type or change the type of their first parameter or apply the `[MappaIgnore]` attribute.                                                                               |
| MP00005 | ⛔    | A strategy cannot be identified.                                                                                                                             | Change the source type or the target type or implement the mapping yourself or apply the `[MappaIgnore]` attribute.                                                                                                     |
| MP00007 | ⛔    | Multiple attributes target the same parameter or property.                                                                                                   | Remove one or more of the attributes targeting the same type.                                                                                                                                                           |
| MP00008 | ⛔    | Cannot detect a suitable method to invoke when using the `[MappaInvokeMethod]` attribute.                                                                    | Remove the `[MappaInvokeMethod]` attribute or make sure the desired method exists.                                                                                                                                      |
| MP00009 | ⛔    | The type cannot be correctly identified when using the `[MappaInvokeMethod]` attribute.                                                                      | Remove the `[MappaInvokeMethod]` attribute or make sure the desired type exists.                                                                                                                                        |
| MP00010 | ⛔    | The field or property cannot be identified when using the `[MappaInvokeMethod]` attribute.                                                                   | Remove the `[MappaInvokeMethod]` attribute or make sure the desired field or property exists inside the mapper class.                                                                                                   |
| MP00011 | ⛔    | The `[MappaAssignFromContext]` attribute cannot be used when the method does not have a `MappaContext` as second parameter.                                  | Remove the `[MappaAssignFromContext]` attribute or make sure that the method accept a `MappaContext` as second parameter.                                                                                               |
| MP00012 | ⚠️   | The user has defined `UserDefined` for `CultureInfoSetting` but the `CultureName` has not been defined.                                                      | Remove the usage of `UserDefined` `CultureSettings`, replace the `CultureSettings` to be invariant or current culture or define a culture name.                                                                         |
| MP00013 | ⚠️   | The settings define a format but not a culture therefore the `ParseExact` method cannot be used.                                                             | Remove the format or define a culture in the settings.                                                                                                                                                                  |
| MP00014 | ⚠️   | The property setter is not accessible and therefore the property cannot be mapped.                                                                           |                                                                                                                                                                                                                         |
| MP00015 | ⛔    | The method has too many `[MappaUseProperty]` attributes targeting the same property.                                                                         | Remove the `[MappaUseProperty]` in excess.                                                                                                                                                                              |
| MP00016 | ⚠️   | A dependency introduced via `[MappaDependency]` attribute or `[MappaStaticDependency]` attribute does not provide any method that could be used for mapping. | Remove the dependency.                                                                                                                                                                                                  |
| MP00017 | ⚠️   | A non required property cannot be mapped and therefore will be ignored.                                                                                      | The warning can be ignored if this is expected or you can apply any of the mapping attributes to that property (`[MappaAssignFromConstant]`, `[MappaAssignFromContext]`, `[MappaInvokeMethod]`,  `[MappaUseProperty]`). |
| MP00018 | ⛔    | A value provided via `[MappaAssignFromConstant]` for an enumeration target type cannot be used because the enumeration does not have such value.             | Provide a correct value for the enumeration or remove the attribute.                                                                                                                                                    |
